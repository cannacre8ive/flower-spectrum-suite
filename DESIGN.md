# Design system

Preserves the supplied editorial palette and aroma identity. New suite navigation and portfolio pages extend that language with open spacing, large serif headings, compact metadata, and real interface previews.

- Background `#0e0e0c`; surface `#181715`; rules `#2a2824`.
- Primary text `#e8e3d9`; secondary text `#a8a092`; accent `#6AAFA0`.
- Paper `#f4eee3`; paper ink `#1a1816`.
- Display: Newsreader. UI: DM Sans. Metadata: JetBrains Mono. Fonts bundled from Fontsource.
- Profile colors: Gas `#C9A84C`, Earth `#6B8E5A`, Citrus `#D4A843`, Fruit `#B75F4A`, Floral `#B98BBE`, Dessert `#D6B58A`, Spice `#9E6B4A`, Pine `#4F7A5B`, Herb `#7FA688`, Tropical `#D28B49`.
- Layout: 20–24px card padding, 20px grid gaps, 6% desktop gutters, 20px mobile gutters.
- Fixed-order fingerprint sectors convey relative model scores. Bands show up to three profiles meeting 60% of the leading score. Neither chart is a laboratory concentration chart.
- Responsive suite collapses to one column. Menu navigation becomes horizontally scrollable on phones. Creative canvases retain native dimensions and scale for preview.
- Focus outlines and reduced-motion support. The source education palette and small print type are retained; this is not a claim of WCAG certification.
