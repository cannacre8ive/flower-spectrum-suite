# Source and adaptation map

| Supplied artifact | Preserved original | Working module |
|---|---|---|
| Cultivator Social Kit v1.0 | `source/cultivator-social-kit.html` | `social.html`, `src/modules/social.js` |
| Tablet Menu v0.3 | `source/tablet-menu.jsx` | `src/modules/TabletMenu.jsx`, `src/lib/menu-data.js` |
| Education Materials v1.1 | `source/education-materials.jsx` | `src/modules/Education.jsx`, `src/data/terpenes.js` |

All supplied bytes are preserved; hashes are in `source/manifest.json`. The supplied HTML ended at `</body>`; its working copy has a closing `</html>`. Original version/build labels remain in the modules where they identify source lineage. The integrated suite release is 1.0.0.

Shared profile names, keys, colors, and extended descriptions use the education source. The tablet's shorter driver labels are generated from the shared array. Classification math and compact terpene weights use the social source. Historical sample raw analyte labels (including the original limonene label, farnesene distinctions, trans-Phytol, and unsupported Anisole) remain unaltered.

Source assertions about lab validation are inherited claims, not newly verified evidence. Three historical sample panels are transcriptions supplied by the user. Original laboratory PDF files were not attached. The compact model excludes unmodeled analytes and is not a clinical or sensory validation study. Educational references to traditional effects are retained as source copy and require editorial review before retail use.

The existing `flower-spectrum-studio` project was inspected only to avoid a naming collision; it was not modified or reused as a source.
