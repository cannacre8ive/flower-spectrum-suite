# Flower Spectrum Suite

A unified product and brand demonstration connecting aroma-first retail browsing, print education, and cultivator creative output. Audiences: portfolio reviewers, retail operators evaluating the concept, staff educators, and cultivator marketers.

## User stories
- Explore one visual system across all three original prototypes.
- Browse flower, filter by aroma, inspect details, staff picks, and sample sales.
- Edit a local catalog and export/import the suite's own CSV format without data loss.
- Learn from nine supplied educational pieces; use the preference quiz to open a matching menu view.
- Choose a historical sample, customize farm branding, and export six social formats.
- Download a portfolio case study, real application screenshots, and a complete asset kit.

## Acceptance criteria
All three source files are preserved with hashes. Ten canonical profile identities are shared. Three social sample panels drive matching menu bands. All suite routes work at desktop and 320px widths. Core CSV round trips and classifier regression checks pass. Downloaded files have the declared dimensions. The stable live demo and social-preview image return HTTP 200.

## Boundaries
This is a portfolio demonstration. No live inventory, checkout, medical recommendations, production access control, cloud sync, arbitrary lab/POS mapping, or independent COA verification. No business performance uplift is claimed.

## Version 2 delivered

The classifier, print menu and PDF labels are integrated with the digital catalog. All ten profiles have downloadable PNG cards and SVG fingerprint diagrams. Print categories, staff picks, deals, profile cards, terpene cards, grouping, sorting, visibility, page orientation, and column controls preserve the source workflow. Labels support selection, grouped/interleaved copies, optional cut guides, and a partially used sheet. Wholesale commerce remains reference-only; no inventory availability is asserted by these sample tools.

## Version 3 delivered

Farms upload PDF/CSV/image reports plus optional flower photographs, review source rows and totals, then create fingerprint-led social and chemovar assets. Buyers search the local flower catalog by aroma and specific terpene concentration, shortlist batches, export a CSV, and pass the selection to Print menu. Retail staff use flower-only digital menus, profile education, and automatically refreshed label PDF previews. The farm, buyer, and staff journeys are illustrated in Workflows. Non-flower seed records remain preserved in storage but are excluded from the retail, print, and label UIs.
