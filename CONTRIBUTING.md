# Contributing

Use Node 22.12+ (or a newer supported LTS), run `npm ci`, then `npm run dev`. Run `npm run check` before committing. Use focused branches such as `feature/social-export` or `fix/catalog-import` and describe changes plus verification.

Never edit `source/` originals. Modify the adapted modules instead and document the difference. Shared profile identities belong in `src/data/profiles.js`; do not create another palette. Preserve raw lab labels and keep unsupported analytes visible. Mark illustrative data and unverified claims. Do not add credentials or private operational data to this public project.

Update CHANGELOG and README with every meaningful release. Capture real screenshots after visible UI changes. Keep portfolio downloads aligned with the deployed application.
