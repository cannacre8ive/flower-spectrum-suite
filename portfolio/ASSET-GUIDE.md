# Portfolio asset guide

- `public/assets/flower-spectrum-case-study.pdf`: four-page introduction, system story, real interface examples, and source boundaries.
- `public/assets/portfolio-cover.png`: 1600 × 1000 real app screenshot for a portfolio feature.
- `public/assets/social-preview.png`: 1200 × 630 real app screenshot for link sharing.
- `documentation/assets/`: desktop and mobile screenshots embedded in the GitHub README.
- `public/assets/fs-*.png`: native-size outputs from the actual cultivator studio.
- `public/assets/education-primer.pdf`: print export of the supplied primer, with source editorial notice.
- `public/assets/flower-spectrum-portfolio-kit.zip`: shareable outputs plus editable case-study HTML and captions.
- `portfolio/case-study.html`: editable, self-contained case study source with embedded screenshots.

The full application and original JSX/HTML remain editable. Social templates can be customized in the Social Studio. PNGs are flat exports, not layered design files. Fonts are bundled in the app; embedded screenshots in the case study preserve its visual appearance when shared.

Use the stable demo URL in posts. Do not describe illustrative prices as current prices or portfolio samples as live stock. Original lab PDFs and retail approval are not part of this project.
